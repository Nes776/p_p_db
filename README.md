#  База данных «Отдел кадров института» (HR Database)

Комплексный проект по проектированию, разработке и аналитической обработке реляционной базы данных для автоматизации кадрового учёта высшего учебного заведения. 

Проект демонстрирует полный цикл работы с данными: от проектирования схемы и обеспечения целостности (Data Engineering) до написания сложных аналитических запросов и генерации отчётов (Data Analysis).

  Стек технологий
*   СУБД: Microsoft SQL Server
*   Язык запросов: T-SQL
*   Инструменты: SQL Server Management Studio (SSMS), Database Diagram Designer
*   Методологии: Реляционное проектирование, Нормализация (3НФ), ER-моделирование

##  Архитектура и проектирование БД 

*   Нормализация: Схема приведена к **третьей нормальной форме (3НФ)**. Устранены частичные и транзитивные зависимости, данные декомпозированы для минимизации избыточности.
*   Масштаб: База данных включает **20 таблиц**, покрывающих все аспекты кадрового учёта (сотрудники, паспорта, образование, учёные степени, отпуска, воинский учёт, аудит).
*   Целостность данных: Реализована через `PRIMARY KEY`, `FOREIGN KEY`, ограничения `UNIQUE`, `CHECK` (валидация дат, возраста, категорий) и `DEFAULT`.
*   Иерархия: Реализована рекурсивная связь «один ко многим» для структуры подразделений (родительское подразделение -> дочерние).
*   Индексация: Созданы индексы (`IX_employees_name`, `IX_appointments_dates` и др.) для оптимизации производительности поиска и аналитических выборок.

##  Аналитические возможности 

Для поддержки принятия управленческих решений реализованы следующие аналитические инструменты:

*   Представления (Views):
    *   `v_employee_full_info`: Сводная информация по действующим сотрудникам (возраст, стаж, должность, отдел).
    *   `v_vacancies`: Анализ вакансий и свободных ставок по подразделениям.
    *   `v_current_leaves`: Оперативный отчёт по сотрудникам в отпусках.
    *   `v_department_staffing`: Укомплектованность отделов, фонд оплаты труда (ФОТ) и средний стаж.
*   Функции (Functions):
    *   Скалярные: `fn_calculate_experience` (расчёт стажа), `fn_calculate_pension_age` (расчёт даты выхода на пенсию по полу и дате рождения).
    *   Табличные: `fn_get_department_employees` (сотрудники отдела), `fn_get_employee_children` (дети сотрудника с расчётом возраста).
*   Курсоры (Cursors):
    *   `sp_calculate_department_stats_cursor`: Пошаговый расчёт статистики по всем подразделениям с агрегацией данных по ФОТ и средней зарплате.

##  Автоматизация и бизнес-логика 

*   Хранимые процедуры (Stored Procedures):
    *   Реализованы транзакционные процедуры для приёма (`sp_add_new_employee`), назначения (`sp_assign_employee_position`) и увольнения (`sp_dismiss_employee`) сотрудников.
    *   Использован механизм `TRY...CATCH` для обработки ошибок и отката транзакций (`ROLLBACK`) для поддержания ACID-свойств.
*   триггеры (Triggers):
    *   `trg_after_employee_insert`: Автоматическое создание записи о семейном положении при приёме на работу.
    *   `trg_instead_of_employee_delete`: Реализация «мягкого удаления» (soft delete) — вместо физического удаления сотрудник помечается как уволенный.
    *  `trg_after_salary_update`: Аудит изменений зарплат (логирование старых и новых значений в таблицу `audit_log`).
    *   `trg_check_hire_age`: Валидация возраста сотрудника (от 18 до 70 лет) при приёме.

## Структура репозитория

*   `main.sql` — DDL-скрипты: создание БД, таблиц, ограничений и индексов.
*   `заполнение бд.sql` — DML-скрипты: генерация реалистичного тестового набора данных (сотрудники, приказы, отпуска и т.д.).
*   `view.sql` — скрипты создания аналитических представлений.
*   `function.sql` — скалярные и табличные функции для расчёта метрик.
*   `procedure.sql` — хранимые процедуры для автоматизации кадровых операций.
*   `triggers.sql` — триггеры для обеспечения целостности и аудита.
*   `cursor.sql` — курсорная процедура для глубокой аналитики по отделам.
*   `примеры.sql` — примеры аналитических запросов и вызовов процедур.
*   `БД_КДЗ_Нечепорук_БИВТ-24-8.docx` — полная пояснительная записка (ER-диаграмма, анализ зависимостей).

##  Примеры использования (Бизнес-кейсы)

**1. Анализ квалификации преподавательского состава:**
```sql
SELECT 
    e.last_name + ' ' + e.first_name AS employee_name,
    d.name AS department,
    edu.education_level,
    ei.name AS institution,
    at.title_name,
    at.defense_date
FROM employees e
JOIN appointments a ON e.employee_id = a.employee_id 
    AND (a.dismissal_date IS NULL OR a.dismissal_date > GETDATE())
JOIN staff_positions sp ON a.staff_position_id = sp.position_id
JOIN departments d ON sp.department_id = d.department_id
LEFT JOIN education edu ON e.employee_id = edu.employee_id
LEFT JOIN educational_institutions ei ON edu.institution_id = ei.institution_id
LEFT JOIN academic_titles at ON e.employee_id = at.employee_id
WHERE d.department_type = 'academic'
ORDER BY d.name, e.last_name;
